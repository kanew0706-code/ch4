# 建立 Discord Server 與頻道（Windows）

照這份做完，你會拿到：

- 一個你自己的 Discord Server（伺服器）
- 一個給 agent 用的頻道，以及它的 **CHANNEL_ID**
- 一條邀請連結，可以讓同組同學加入

> Discord 偶爾會改版，按鈕位置可能和這裡寫的有一點出入。找不到時，看按鈕上的英文或圖示，通常就在附近。
> 下面寫的位置以 Discord 電腦版 App 為準。介面是中文還是英文都可以，按鈕名稱兩種都會寫出來。

---

## 第 0 步：準備 Discord

1. 打開瀏覽器，到 <https://discord.com/download>，按「Download for Windows」下載。
2. 執行下載好的 `DiscordSetup.exe`，等它自動安裝完並打開。
3. 用你的帳號登入；沒有帳號就按「註冊」（Register）建立一個。
4. 建議到信箱收認證信、完成 Email 驗證。有些操作（例如建立 bot）會要求帳號已經驗證過。

---

## 第 1 步：建立你自己的 Server

1. 看 Discord 視窗**最左邊那一排圓形圖示**，拉到最下面，按綠色的 **「＋」**（滑鼠移上去會顯示「新增伺服器」／Add a Server）。
2. 跳出視窗後，選第一個 **「自行建立」**（Create My Own）。
3. 下一頁問你這個伺服器給誰用，選 **「供我和我的朋友使用」**（For me and my friends）。
4. 在「伺服器名稱」（Server Name）欄位輸入名字，例如 `食物記錄測試`。圖示可以不放。
5. 按右下角的 **「建立」**（Create）。
6. 完成後，左邊那一排會多一個新圖示，畫面也會自動切到這個新的 Server。

---

## 第 2 步：建立給 agent 用的頻道

1. 在畫面**左邊第二欄**（頻道清單），找到 **「文字頻道」**（TEXT CHANNELS）這個標題。
2. 滑鼠移到這個標題上，右邊會出現一個小小的 **「＋」**，按下去。
3. 「頻道類型」（Channel Type）選 **「文字」**（Text）。
4. 「頻道名稱」（Channel Name）輸入例如 `food-log`。
5. 下面有一個 **「私人頻道」**（Private Channel）開關，**先不要打開**。
   - 這個 Server 只有你邀請的人進得來，一般頻道就夠了。
   - 如果打開私人頻道，之後還要另外把 bot 和每個同學加進這個頻道，步驟比較多。
6. 按 **「建立頻道」**（Create Channel）。
7. 左邊頻道清單會出現 `# food-log`。

> 為什麼只開一個頻道給 agent：agent 只會聽這一個頻道。這個頻道的人每傳一張照片，就會用掉一次你的 Claude 額度（見 `architecture.md` 第 13 節）。

---

## 第 3 步：打開「開發者模式」

要先打開這個模式，才能複製頻道的 ID。

1. 看畫面**左下角**，你的頭像和名字旁邊有一個 **齒輪 ⚙️**（使用者設定／User Settings），按下去。
2. 設定畫面左邊是一長串選單，往下捲到 **「應用程式設定」**（App Settings）這一區。
3. 按 **「進階」**（Advanced）。
4. 右邊第一個開關是 **「開發者模式」**（Developer Mode），把它打開（變成綠色）。
5. 按右上角的 **✕** 或鍵盤 `Esc` 離開設定。

---

## 第 4 步：拿到 CHANNEL_ID

1. 在左邊頻道清單，對 `# food-log` 按 **滑鼠右鍵**。
2. 選單最下面會出現 **「複製頻道 ID」**（Copy Channel ID），按下去。
3. 打開「記事本」，按 `Ctrl + V` 貼上，你會看到一串 17～20 位的數字，例如 `123456789012345678`。這就是 **CHANNEL_ID**。
4. 先把這串數字記下來，後面填 `.env` 時會用到。

> 注意不要按成「複製伺服器 ID」（Copy Server ID），那是整個 Server 的編號，不是頻道的。
> CHANNEL_ID 不是密碼，被別人看到沒關係，但也沒必要公開。

---

## 第 5 步：產生邀請連結，讓同學加入

1. 看左邊頻道清單**最上面**的 Server 名稱（例如「食物記錄測試」），按一下名稱，會往下展開一個選單。
2. 按 **「邀請其他人」**（Invite People）。
3. 跳出的視窗最下面有一行小字 **「編輯邀請連結」**（Edit invite link），按下去。
4. 設定兩項：
   - **「到期時間」**（Expire After）：選 **7 天**（7 days），測完就自動失效。
   - **「使用次數上限」**（Max Number of Uses）：填同組人數，例如 **5 次**（5 uses）。
5. 按 **「產生新連結」**（Generate a New Link）。
6. 回到上一個畫面，按連結右邊的 **「複製」**（Copy）。
7. 把連結傳給同組同學。他們點開連結、按「接受邀請」（Accept Invite），就會加入你的 Server。

> **為什麼要設期限和次數**：拿到連結的人都能進來，進來的人都能在 `food-log` 傳照片、用掉你的額度。所以只給同組同學，而且讓連結自己過期。

### 測試完想收回邀請連結

1. 按左上角 Server 名稱 → **「伺服器設定」**（Server Settings）。
2. 左邊選單按 **「邀請」**（Invites）。
3. 滑鼠移到那條邀請上，右邊會出現 **✕**，按下去就撤銷。

### 想把某個人請出 Server

在右邊成員清單，對那個人按滑鼠右鍵 → **「踢出」**（Kick）。

---

## 完成檢查

- [ ] 左邊那一排看得到你的 Server
- [ ] Server 裡有 `# food-log` 頻道
- [ ] 記事本裡有一串數字的 CHANNEL_ID
- [ ] 同組同學已經用邀請連結加入，出現在右邊的成員清單

下一步：照 [discord-bot-setup.md](discord-bot-setup.md) 建立 bot，並把它邀進這個 Server。
